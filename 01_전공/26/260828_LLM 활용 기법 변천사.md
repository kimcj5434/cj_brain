### LLM 활용 방식 및 핵심 기법 변천사 (연도순)

| 연도 / 시기  | 발전 단계          | 주요 기법 및 패러다임 (대화 외 내용 포함)                      | 발생 배경 및 해결하고자 한 문제                                                                  | 결과물 및 대표 기술                                            |
| -------- | -------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 2022년 초  | 1. 프롬프트 기초     | Prompting, Few-Shot                            | LLM에게 단순히 질문만 하면 환각이나 오답이 잦음. 예시를 주고 질문 구조를 다듬어 성능 개선.                              | Direct Prompting, Few-shot Prompting                   |
| 2022년 말  | 2. 추론 방식 개선    | CoT (Chain of Thought), ReAct                  | complex한 문제를 한 번에 풀지 못함. "단계별로 생각해봐(CoT)"라는 추론 과정을 주입하고, 생각(Reason)+행동(Act) 패턴을 유도. | CoT, ReAct Framework, LangChain (2022.10)              |
| 2023년 중순 | 3. 지식 연동 & 도구  | RAG, Function Calling                          | 외부 지식 반영 불가능 문제 해결(RAG). 코드/API를 LLM이 직접 호출할 방법을 모델 차원에서 제공(Function Calling).      | RAG, OpenAI Function Calling (2023.06)                 |
| 2023년 말  | 4. 역할 분담 에이전트  | Subagent (Multi-Agent)                         | 단일 LLM에게 모든 역할을 시키면 context 매몰 발생. 기획자, 개발자 등 역할을 나눈 소형 agent 팀 구성.                 | Microsoft AutoGen (2023.10), CrewAI (2023.11)          |
| 2024년 초  | 5. 제어 및 안전망    | Harness, Guardrails                            | Agent의 자의적 행동, 무한 루프, 사내 규정 위반 방지. 결정적 코드(Deterministic Code) 및 사람 승인(HITL) 배치.     | LangGraph (2024.01), Guardrails AI, Human-In-The-Loop  |
| 2024년 말  | 6. 표준화 및 파이프라인 | MCP, Context Caching, Dynamic Rag              | 도구 연동 인터페이스 파편화 해결(MCP). 토큰 비용/속도 한계를 극복하기 위해 Context Caching 등 도입.                 | Anthropic MCP (2024.11), Gemini Context Caching, SKILL |
| 2025년 이후 | 7. 자율 운영 시스템   | Agentic Workflow Evaluation, Agent Memory (신규) | 단순 텍스트 기록을 넘어 에이전트가 경험을 습득하는 단기/장기 메모리 Architecture 도입 및 에이전트 평가(Eval) 자동화.         | MemGPT/Zep (에이전트 메모리), Agent Eval Frameworks           |
