### 온톨로지 구현 시 유용한 대표 플러그인

1. **Open ontologies**: RDF 기반의 온톨로지를 구현한 것 같음.
2. **Dataview:** 노트들에 부여된 속성과 관계 데이터를 SQL/DQL 쿼리로 조회하여, 온톨로지 기반의 추론 및 분류 표를 생성해 줍니다.
    
2. **Breadcrumbs:** 상하 관계(`parent`/`child`), 형제 관계(`sibling`), 이전/다음 관계(`next`/`prev`) 등 명확한 계층/방향성 온톨로지를 정의하고 탐색하게 도와줍니다.
    
3. **Juggl / Excalibrain:** 노트 간 작성된 서맨틱 관계(`is_a`, `part_of` 등)를 읽어와, 선 위에 관계 명칭이 표시되는 진짜 온톨로지 지식 그래프(Knowledge Graph)를 시각화합니다.


시맨틱 웹(Semantic Web)은 컴퓨터가 사람처럼 **웹 문서의 '의미(Semantic)'를 이해하고 처리할 수 있도록 만든 차세대 웹 기술 개념**이며, **RDF**는 이를 구현하기 위한 **표준 데이터 표현 구조**입니다.

### 1. 시맨틱 웹 (Semantic Web)이란?

현재 우리가 쓰는 일반적인 웹은 '사람을 위한 웹'입니다.

- 사람이 글을 읽으면 "아, 브렌던 아이크가 자바스크립트를 개발했구나"라고 자연스럽게 이해하지만, 컴퓨터 눈에는 그저 `<html>`, `<h1>`, `<span>` 같은 **디자인 태그로 둘러싸인 단순 텍스트 덩어리**일 뿐입니다.
    

**시맨틱 웹은 이를 '컴퓨터도 이해할 수 있는 웹'으로 바꾸는 데이터 네트워크입니다.**

문서와 문서 간의 링크뿐만 아니라, "어떤 개념(A)이 다른 개념(B)과 무슨 관계인가"를 컴퓨터가 읽을 수 있는 명확한 의미 정보(메타데이터)로 부여합니다.

### 2. RDF (Resource Description Framework) 데이터 모델이란?

시맨틱 웹에서 지식과 데이터 관계를 컴퓨터가 이해할 수 있는 형태로 표현하는 **W3C 국제 표준 데이터 모델**입니다.

RDF의 핵심 원리는 모든 정보를 `주어(Subject) - 술어(Predicate) - 목적어(Object)`라는 3가지 요소의 조합, 즉 **주술목(Triple)** 형태로 쪼개어 표현하는 것입니다.

- **예시 문장:** "자바스크립트는 브렌던 아이크가 개발했다."
    
- **RDF 표현 (Triple):**
    
    - **주어 (Subject):** `자바스크립트` (개체)
        
    - **술어 (Predicate):** `~에 의해 개발됨` (관계/속성)
        
    - **목적어 (Object):** `브렌던 아이크` (개체)
        

```
[자바스크립트] ──(개발됨)──> [브렌던 아이크]
      │
  (속함)
      ▼
[프로그래밍 언어]
```

이 주술목(Triple)들이 수천, 수만 개가 얽히고설키면서 만들어지는 거대한 네트워크가 바로 지식 그래프(Knowledge Graph)이며, 온톨로지의 핵심 뼈대가 됩니다.

### 요약 및 비교

|**구분**|**일반 웹 (Traditional Web)**|**시맨틱 웹 / RDF (Semantic Web)**|
|---|---|---|
|**연결 방식**|문서와 문서 간 단순 연결 (`<a>` 태그)|데이터(개체)와 데이터 간 의미 연결|
|**주요 대상**|사람 (화면에 예쁘게 보여주는 목적)|컴퓨터 및 AI (의미를 해석하고 추론하는 목적)|
|**데이터 형태**|비구조화된 HTML 텍스트|RDF 기반 구조화 데이터 (Triple 네트워크)|
|**옵시디언 비유**|단순 노트 링크 `[[자바스크립트]]`|속성 기반 서맨틱 링크 `[개발자:: [[브렌던 아이크]]]`|
